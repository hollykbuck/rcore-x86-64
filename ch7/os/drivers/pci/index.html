PCI bus enumeration for QEMU q35.

The q35 machine exposes the PCIe Enhanced Configuration Access Mechanism (ECAM) as MMIO at a base programmed in the MCH’s PCIEXBAR register (config space offset 0x60). OVMF may move it away from QEMU’s default 0xB0000000, so we read it at runtime through the legacy IO-port CAM (0xCF8/0xCFC), map the window through the physmap, and then use virtio-drivers’ PciRoot/PciTransport over that MMIO ECAM.
