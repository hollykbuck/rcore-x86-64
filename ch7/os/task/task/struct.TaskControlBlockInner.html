§trap_cx_ptr: usize

virtual address of the TrapContext on this process’s kernel stack. The kernel stack lives in the shared kernel high-half mapping, so this address is valid under any active page table.

§killed: bool

true if the task is killed by a signal (or SIGKILL)

§frozen: bool

true if the task is frozen by SIGSTOP, waiting for SIGCONT
