Interior mutability primitives backed by a spinlock.

On x86-64 the kernel runs with IF cleared (interrupts only happen in user mode), so while the kernel holds one of these locks it cannot be preempted on the same core; another core spins with pause until the lock is released (Intel SDM: PAUSE improves spin-wait performance).

In order to get mutable reference of inner data, call exclusive_access.
