pub fn enable_timer_interrupt()
Expand description

The timer interrupt is enabled by the user RFLAGS IF bit (see context::TrapContext::app_init_context) together with the APIC timer setup done by crate::timer::init. The kernel itself deliberately keeps IF cleared (interrupt gates and SFMASK) so that external interrupts only happen in user mode, mirroring how RISC-V ch3 only enables stimer in user mode. Nothing needs to be done here.
