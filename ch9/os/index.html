The main module and entrypoint

Various facilities of the kernels are implemented as submodules. The most important ones are:

  • trap: Handles all cases of switching from userspace to the kernel
  • task: Task management
  • syscall: System call handling and implementation

The operating system also starts in this module. Kernel code starts executing from _start (defined in limine_reqs.rs), after which rust_main() is called to initialize various pieces of functionality. (See its source code for details.)

We then call task::add_initproc() and let the scheduler (task::run_tasks()) bring up the init process and everything after it.
