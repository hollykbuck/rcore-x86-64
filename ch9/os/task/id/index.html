os::task

Source
Expand description

Per-thread resources: the kernel-stack allocator, the per-thread user stack, and a recycle allocator for tids.

x86-64 note: unlike RISC-V, the TrapContext of a thread lives on the thread’s kernel stack (see KernelStack::push_context), so there is no trap_cx page in user space. Only the per-thread user stack is mapped into the process’s address space here.
