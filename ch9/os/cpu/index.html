Module cpu

Expand description

Per-processor state (SMP, ch8 stage 3).

Each processor gets a PerCpu slot in the static PER_CPU array. The slot address is installed as this core’s GS.base (MSR_GS_BASE) at initialization, and trap.S uses swapgs on trap entry/exit so that the kernel always runs with GS pointing at the current core’s PerCpu. The first field (cpu_id) is therefore readable with gs:[0].
