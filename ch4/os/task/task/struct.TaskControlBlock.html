Fields§

§task_status: TaskStatus§task_cx: TaskContext§memory_set: MemorySet§trap_cx_ptr: usize

virtual address of the TrapContext pushed on this task’s kernel stack. The kernel stack lives in the shared kernel high-half mapping, so this address is valid under any active page table.
