Trap handling functionality

For rCore on x86-64, there are two entry points:

  • the syscall entry, whose address is stored in the LSTAR MSR. It synthesizes an interrupt-like frame and forwards to trap_handler().
  • the exception stubs, pointed to by the IDT. The CPU switches to the kernel stack (the rsp0 field of the TSS) and pushes the interrupt frame, then each stub forwards to trap_handler().

trap_handler() then calls different functionality based on what exactly the exception was. For example, syscalls go to syscall().
